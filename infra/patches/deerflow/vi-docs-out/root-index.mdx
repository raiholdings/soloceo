# Tài liệu DeerFlow

DeerFlow là một framework để xây dựng và vận hành các hệ thống agent. Nó cung cấp một harness runtime để lắp ghép agent với bộ nhớ, công cụ, kỹ năng (skill), sandbox và sub-agent, đồng thời cung cấp một lớp ứng dụng biến những năng lực đó thành trải nghiệm sản phẩm dùng được ngay.

Bộ tài liệu này được tổ chức quanh hai phần đó:

- **DeerFlow Harness**: SDK lõi và lớp runtime để xây dựng hệ thống agent của riêng bạn.
- **DeerFlow App**: ứng dụng tham chiếu xây trên Harness, phục vụ triển khai, vận hành và luồng làm việc của người dùng cuối.

Nếu bạn muốn hiểu DeerFlow hoạt động thế nào, hãy bắt đầu với phần Giới thiệu. Nếu muốn xây dựng trên runtime lõi, xem tài liệu Harness. Nếu muốn triển khai và sử dụng DeerFlow như một ứng dụng, xem tài liệu App.
